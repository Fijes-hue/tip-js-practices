## Запуск

Из папки `practice-07`: `npm ci`, затем `npm run dev`.
`package-lock.json` уже входит в заготовку.
Адрес по умолчанию: http://127.0.0.1:5173/.
Проверки: `npm test`. Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Результат

Приложение отображает 12 задач и три категории, позволяет создавать, редактировать, переключать статус и удалять задачи. Фильтры (поиск, статус, приоритет, категория) применяются совместно, статистика считается по полному набору, пустая выборка сопровождается сообщением.

## Компоненты и состояние

| Состояние | Где хранится | Почему                                                               |
| --------- | ------------ | -------------------------------------------------------------------- |
| tasks     | App          | Единственный источник задач для списка, формы, статистики            |
| filters   | App          | Применяется к tasks при вычислении visibleTasks                      |
| editingId | App          | Идентификатор редактируемой записи; сама задача вычисляется из tasks |
| draft     | TaskForm     | Локальные поля формы, не нужны другим компонентам                    |
| errors    | TaskForm     | Сообщения об ошибках конкретной формы                                |

## Индивидуальный вариант

**Начальный фильтр:** `{ completed: 'false', priority: 'high', categoryId: '2' }` — в выборке только 2 задачи: `id = 4` и `id = 34` (обе невыполненные, высокого приоритета, категория «Проект»).

**Действие:**

1. Создать задачу «Проверить вариант 8», приоритет «Высокий», категория «Проект».
2. Отметить её выполненной.
3. Сбросить фильтры.

**Ожидаемый результат:**

- На шаге 1 задача появляется в выборке: Найдено 3, статистика 13 / 5 / 8.
- На шаге 2 задача исчезает (фильтр `completed: 'false'`): Найдено 2, статистика 13 / 6 / 7.
- На шаге 3 фильтры сброшены, видны все 13 задач, включая новую (она помечена выполненной).

**Ожидаемый результат:**

Начальные фильтры варианта 8: completed: 'false', priority: 'high', categoryId: '2'; после запуска видно 2 задачи из 12, статистика по полному набору — 12 / 5 / 7

## Вывод

В ходе работы изучены функциональные компоненты, useState, управляемые формы, неизменяемые обновления и вычисляемые производные данные. Приложение отображает 12 задач и три категории, поддерживает создание, редактирование, переключение статуса, удаление с подтверждением, совместные фильтры и статистику.
